## Project documentation

Each project folder contains a dedicated overview. Workflow exports, screenshots and other implementation evidence will be added where available.

## Responsible automation

- Credentials, API keys and access tokens must be stored in platform credential managers, never committed to this repository.
- Workflow exports must be reviewed and sanitised before publication.
- Screenshots and sample data must not expose personal, customer or confidential business information.
- AI-generated outputs should be checked by a human before consequential use or external distribution.
